# Gym Tracker

Anand's day-by-day fat-loss and muscle plan as an installable phone app. Each day shows its meals, workout and habits to tick off, with exercise photos, muscle maps, in-app form videos, a set logger, a rest timer and progress charts.

**Live app:** https://anand7474.github.io/gym-tracker/

## Install on your phone

1. Open the live link in Chrome (Android) or Safari (iPhone).
2. Android: menu ⋮ → **Add to Home screen / Install app**. iPhone: Share → **Add to Home Screen**.
3. It opens full-screen like a normal app and works offline in the gym. Videos need internet.

## What's inside

| Screen | What you can do |
| --- | --- |
| Today | Opens on today's date. Tick meals (kcal and protein add up), water glasses, steps, sleep, morning weight. Each exercise has start/finish photos, a muscle map, a form video that plays inside the app, how-to steps, a rest timer and kg × reps logging that shows last session's numbers. |
| Progress | Weight trend against the 85 kg goal, streak, consistency calendar, muscles trained this week, best sets on key lifts, Sunday waist log. |
| Plan | Targets, weekly split, training and food rules, when to adjust, sync setup and backup. |

Weeks 1–2 (from 5 Nov 2026) automatically show the lighter set counts.

## Your data

- Everything saves on the device first (IndexedDB), so the app works with no account and no internet.
- **Plan → Backup** downloads your whole log as a JSON file and can restore it.
- **Optional sync** between phone and laptop uses your own free Supabase project:
  1. Create a project at [supabase.com](https://supabase.com).
  2. Open **SQL Editor**, paste [`supabase/schema.sql`](supabase/schema.sql) and run it. Row-level security means only you can read your rows.
  3. In **Authentication → URL Configuration**, add `https://anand7474.github.io/gym-tracker/` to the redirect URLs.
  4. Copy **Project URL** and the **anon public** key from Project Settings → API.
  5. In the app, go to **Plan → Sync across devices**, paste both, then sign in with the email link. Do this once on each device.
  - Or add them as repo secrets `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` so every build has them built in. The anon key is safe to expose: access is controlled by the row-level security policies.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173/gym-tracker/
npm run build      # type-check + production build into dist/
```

Stack: Vite, React 18, TypeScript, Dexie (IndexedDB), Supabase JS, vite-plugin-pwa, react-body-highlighter. Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.

### Where things live

| Path | Contents |
| --- | --- |
| `src/data/plan.ts` | The weekly plan: meals, exercises, sets/reps, cues, muscles. Edit this to change the program. |
| `src/data/videos.ts` | Form videos per exercise (YouTube ids; first one plays by default). |
| `src/data/library.json`, `public/ex/` | Exercise photos and how-to steps, generated by `tools/build_assets.py`. |
| `src/lib/` | Storage (`db.ts`), Supabase sync (`sync.ts`), stats and dates. |
| `src/components/` | Today, Progress and Plan screens, exercise card, media and visuals. |
